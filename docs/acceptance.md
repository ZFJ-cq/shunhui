# MVP 验收用例

| ID | 模块 | 步骤 | 预期结果/异常 |
|---|---|---|---|
| AUTH-01 | 游客 | 输入昵称登录或创建会议 | 创建游客会话；空昵称拒绝 |
| AUTH-02 | 账号 | 管理员预置手机号账号后登录 | 正确密码成功；错误密码失败 |
| MEET-01 | 即时会议 | 点击快速开会 | 唯一会议号、邀请URL、主持人权限 |
| MEET-02 | 预约 | 填写未来时间、容量和6位密码 | 记录进入我的会议；过去时间/超限容量拒绝 |
| MEET-03 | 入会 | 错误密码、锁定、满员、主持人之前禁入 | 对应请求拒绝，不发房间凭证 |
| MEET-04 | 踢人 | 主持人移除参会人后重入 | 被移除且旧凭证失效；普通成员不可执行；当前额外禁止重入的策略按 C06 待确认 |
| MEET-05 | 结束 | 主持人结束会议 | 全员收到通知并离会，会议号不能重新入会 |
| MEDIA-01 | 设备 | 授权相机/麦克风，切换设备和测试扬声器 | 预览/音量条/测试音正确；拒绝权限可关闭媒体入会 |
| MEDIA-02 | 多人 | 两个独立浏览器开音视频 | 互相收到真实流，不得操作他人transport |
| MEDIA-03 | 共享 | 开启/停止屏幕共享 | 远端可见，结束后状态同步；不支持设备提示 |
| MEDIA-04 | 弱网 | 注入丢包/RTT，断网再恢复 | 显示上下行 RTT/丢包/码率，提示弱网并降低摄像头层；Socket.IO 自动重连后同步成员和媒体订阅，屏幕共享需重新选择 |
| CHAT-01 | 聊天 | 两个客户端发纯文本 | 房间内实时同步；新入会加载历史 |
| CHAT-02 | 聊天 | 主持人关闭聊天后尝试发送 | 服务端拒绝，普通用户不能开关全员聊天 |
| ADMIN-01 | 管理 | 游客访问管理接口 | 403；管理员可查看日志/并发并禁用用户 |
| UI-01 | 界面 | 手机与桌面访问全部页面 | 表单/工具栏可操作，画廊/演讲者可切换 |
| COMPAT-01 | 浏览器 | Chrome、Edge、Safari桌面与手机逐项执行媒体用例 | HTTPS权限和自动播放限制正确提示；微信使用能力降级提示 |

自动测试验证业务、鉴权和真实worker传输创建，不代表已验收真实远端播放。独立NAT公网TURN、跨浏览器音视频、25人负载、端到端时延<300ms仍需部署环境实测。
